# Pugi for Cursor

[Add to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=pugi&config=eyJ1cmwiOiJodHRwczovL2FwaS5wdWdpLmlvL2FwaS9hZ2VudC92MS9tY3AifQ%3D%3D)

The config query is the base64-encoded single-server object in add-to-cursor.json. The full manual configuration is mcp.json. Install, open Customize → MCP servers, connect Pugi and complete browser OAuth. Do not paste an API key into public files. Cursor supports remote Streamable HTTP with OAuth.

.cursor-plugin/plugin.json plus mcp.json is the official Cursor plugin package. Copy this folder's contents to an approved public repository before submitting to https://cursor.com/marketplace/publish; do not submit the private monorepo. The logo is bundled. Test the local package in Cursor before release.
